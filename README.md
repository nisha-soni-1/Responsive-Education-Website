# 🎓 Responsive Education Website — EGATOR

A fully responsive multi-page **Education Website** built using **HTML, CSS, and JavaScript**.  
This project is designed for online learning platforms, coaching centers, and e-learning institutions to showcase courses, testimonials, and more — all in a clean and modern layout.





---

## 🧠 Features
- 🌟 **Fully Responsive Design** for all screen sizes  
- 📚 Courses, Categories, and FAQ sections  
- 💬 **Swiper.js Testimonials Slider**  
- 🎨 Modern UI with Unicons and Google Fonts  
- 📱 Interactive Mobile Navigation Menu  
- ⚡ Lightweight and fast performance  

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Swiper.js** — for testimonial carousel  
- **Unicons** — for icons  
- **Google Fonts** — Montserrat & Poppins
